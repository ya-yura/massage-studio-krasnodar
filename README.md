# Студия массажа и спортивного восстановления

Премиальный mobile-first лендинг для студии в Краснодаре с интерактивным подбором формата массажа и передачей сформированного запроса в WhatsApp.

## Локальный запуск

```bash
npm ci
npm run dev
```

Production-проверка:

```bash
npm run build
npm run build:pages
npm test
npm run lint
```

## Что реализовано

- воронка из 5 шагов: цель → контекст/нагрузка → зона → формат → длительность;
- нейтральный персональный ориентир без медицинских диагнозов и обещаний;
- форма имени, даты, времени и комментария;
- кодирование полного запроса и открытие WhatsApp для номера +7 999 417-99-08;
- возможность отправить запрос с частично заполненными данными;
- мобильная фиксированная CTA-кнопка;
- рейтинги и ссылки на 2ГИС и Яндекс Карты без выдуманных отзывов;
- студия на ул. Хакурате, 12 и сценарий уточнения выезда;
- адаптивная вёрстка, SEO-метаданные и Open Graph без передачи данных на сервер;
- уважительное поведение при `prefers-reduced-motion`.

## Фактические данные

Использованы данные из ТЗ: Краснодар, ул. Хакурате, 12; телефон и WhatsApp +7 999 417-99-08; ссылки на 2ГИС, Яндекс Карты и исходный сайт; рейтинги 5,0 в 2ГИС и 4,8 в Яндекс Картах; перечень направлений массажа.

## Что подтвердить владельцу перед публикацией

- актуальность рейтингов и адреса;
- доступность выездного формата и условия подарочных сертификатов;
- фактическую формулировку бренда/логотипа и рабочий режим;
- необходимость добавить реальные фотографии, если студия хочет использовать их в первом экране;
- домен и финальные настройки GitHub Pages.

## Публикация

Локальный проект подготовлен как статическая витрина без серверной обработки персональных данных. Workflow GitHub Pages публикует production-артефакт из `dist-pages`, собранный отдельной Vite-конфигурацией для подпути репозитория.
